# AI-assisted contributions

AI tools may assist a contribution, but the human author remains responsible for every claim and line submitted.

- Disclose material AI assistance in the pull request and describe its scope.
- Read, understand, and be able to explain the complete change.
- Validate behavior with the same tests and quality gates as human-authored code.
- Never submit mass-generated issues or pull requests.
- Never invent reproduction steps, test results, benchmarks, sources, or changelog entries.
- Never send secrets, private source, vulnerability details, or user data to an external model without authorization.
- Write contributor communication in your own words and respond to review yourself.

Maintainers may close unverifiable or low-quality generated contributions as spam.
