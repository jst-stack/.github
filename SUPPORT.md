# Support

Use the right channel so maintainers and future users can find the answer:

- Ask usage and architecture questions in [JST Discussions](https://github.com/jst-stack/jst/discussions).
- Report reproducible defects through the relevant repository's issue form.
- Propose broad architecture changes in an RFC discussion before implementation.
- Report security vulnerabilities through GitHub private vulnerability reporting, never a public issue.

Include the JST, CLI, and architecture-plugin versions, Node version, package manager, the failing command, and a minimal reproduction when applicable.

Community support is best effort. Sponsorship does not create a private support contract or response-time SLA.
