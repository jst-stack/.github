# JST Stack

JST is an architecture-first React stack for codebases that need to stay understandable as they grow.

It turns engineering conventions into executable checks: dependency direction, module boundaries, naming, file size, public APIs, styles, tests, and production readiness. The same rules guide developers in the editor, block unsafe commits, and keep AI-generated code inside the project's architecture.

```sh
npm create jst@latest my-app
```

The starter includes React, framework SSR, TypeScript, DI, generated routes, CSS or SCSS modules, Docker, unit and end-to-end tests, and a complete quality pipeline. Start with a working product foundation, then add business code without rebuilding the guardrails.

## Community

Ask usage questions, propose architecture changes, and show what you built in [JST Discussions](https://github.com/jst-stack/jst/discussions). Reproducible defects belong in the affected repository's issue tracker; security reports must use private vulnerability reporting.

Contributions follow the organization [governance](https://github.com/jst-stack/.github/blob/main/GOVERNANCE.md), [contribution guide](https://github.com/jst-stack/.github/blob/main/CONTRIBUTING.md), and [AI-assisted contribution policy](https://github.com/jst-stack/.github/blob/main/AI_ASSISTED_CONTRIBUTIONS.md).
